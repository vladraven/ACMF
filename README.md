# ACMF Full v2.4.9 Quebec 70-74 Alpha Sensitivity

This package continues the Quebec 70-74 case study by testing local aging-rate counterfactuals.

## Run

```bash
python empirical/scripts/run_v2_4_9_quebec_70_74_alpha_sensitivity.py
python tests/test_v2_4_9_quebec_70_74_alpha_sensitivity.py
```

## Scope

This is an explanatory sensitivity audit, not an operator-selection model. It tests whether the Quebec 70-74 failure is sensitive to the 65-69→70-74 inflow rate and the 70-74 outflow/stay rate.
